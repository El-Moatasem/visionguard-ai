feat(video): add mobile-friendly recording, ingestion, and playback

DESCRIPTION — COPY INTO GITHUB
## Summary
Adds the first usable VisionGuard ingestion workflow on top of the existing Meta API validation scaffold. A reviewer can upload an authorized short video or record a clip using mobile camera capture, list recorded clips, and play them back in a responsive web interface. Analysis/alerting is explicitly NOT included in this PR.

## Implementation
- FastAPI `POST /api/v1/videos`, listing, metadata, playback with HTTP range requests.
- Streamed size-limited uploads with MP4/MOV/WebM header sniffing, UUID filenames, SHA-256 and metadata manifest.
- Local `var/uploads` storage excluded from Git.
- Next.js 16 + React 19 mobile-first dashboard: upload, HTML camera capture fallback, live camera preview/MediaRecorder and video player.
- Same-origin Next.js proxy `/api/backend/*` to local FastAPI.
- Seven new backend integration tests; original Day 1 tests preserved.
- Frontend typecheck/build CI, README, tracking reliability and benchmark preparation documents.
