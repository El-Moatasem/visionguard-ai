VISIONGUARD AI — RUN AND TEST LOCALLY (VIDEO INGESTION FEATURE)
==============================================================
Prerequisites: Python >=3.11, Node.js >=20.9, npm, Git, macOS/Linux.
No GPU, camera, Meta API key, Render, or Neon needed for upload/playback tests.

FROM REPOSITORY ROOT:

TERMINAL 1 — BACKEND
  python3 -m venv .venv
  source .venv/bin/activate
  pip install -r requirements.txt
  cp -n .env.example .env
  uvicorn backend.app.main:app --reload --port 8000

  http://localhost:8000/docs
  http://localhost:8000/health

TERMINAL 2 — FRONTEND
  cd frontend
  npm install
  npm run typecheck
  npm run build
  npm run dev

  http://localhost:3000

SMOKE TEST FROM TERMINAL 3
  curl http://127.0.0.1:8000/health
  curl http://127.0.0.1:8000/api/v1/videos
  curl -F 'file=@/absolute/path/authorized-short-clip.mp4' http://127.0.0.1:8000/api/v1/videos
  # Copy id from response, and test /api/v1/videos/ID/file in browser.

OFFLINE TESTS
  python -m pytest backend/tests -q

LIVE META API (OPTIONAL; BILLABLE — NOT REQUIRED FOR INGESTION)
  python -m backend.scripts.meta_smoke status
  python -m backend.scripts.meta_smoke muse
  python -m backend.scripts.meta_smoke sam --video samples/warehouse.mp4 --concept person --output outputs/day1

PHONE TEST
  1. First test on desktop at localhost:3000.
  2. 'Capture with phone' launches native camera capture where supported.
  3. getUserMedia preview requires HTTPS/secure context; plain HTTP over LAN
     often blocks camera permissions. Use an HTTPS development tunnel/host and
     appropriate backend connectivity for on-phone live preview.
  4. MediaRecorder may produce WebM; playback works, SAM conversion is NOT yet
     automated. Phone preview is NOT real-time hazard inference.

ENVIRONMENT
  MODEL_API_KEY        used only by Meta smoke CLI in this stage
  VIDEO_STORAGE_DIR    optional local storage directory; default ./var/uploads
  VIDEO_MAX_BYTES      default 26214400 (25 MiB)
  BACKEND_URL          server-side Next.js rewrite, default http://127.0.0.1:8000

CAUTION
  Local storage URLs have no authentication. DO NOT deploy exposed API as-is.
  Do not commit .env files, raw workplace footage, generated output or personal data.
  On Render use private object storage and auth before enabling uploads.
  Neon PostgreSQL is optional only once incident metadata persistence is built.
